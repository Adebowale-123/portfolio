# Portfolio

Personal developer portfolio: a static site (HTML, CSS, a little JavaScript), no build step.

- `index.html`: Home, About, Projects, Skills & Technologies, Experience, Contact
- `projects/*.html`: one case study per project
- `images/`: screenshots of each application (WebP with JPG fallback)

Preview locally with `python -m http.server` and open http://localhost:8000.
Deploys to Render as a static site via `render.yaml`.

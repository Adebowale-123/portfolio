Currency Rate Comparison Platform

LiveAPIsProvider quotes are estimates for now

PAS FX Compare helps people sending money abroad see how much the recipient will actually get, by combining the live market rate with each transfer method's fees and margin.

ProductPAS FX Compare
RoleFull-stack developer
StackNext.js · React · PostgreSQL
StatusLive on Render

The problem

The headline exchange rate rarely tells you what arrives. Fees and hidden margins vary widely between banks, money-transfer apps and cash-pickup services, especially on routes like GBP → NGN. People need one number: how much will my recipient get?

How it works

  • Currencies API: GET /api/currencies serves 160+ currencies with names and symbols for the pickers.
  • Live market rate: the server fetches the mid-market rate for the chosen pair and records when it was updated.
  • Comparison logic: GET /api/compare?from=GBP&to=NGN&amount=1000 applies each transfer method's fee and margin, works out the effective rate and the amount received, and returns the quotes ranked best first, with transfer time.
  • Two directions: you can enter what you send or what they receive; the swap button reverses the pair.
  • Auto-refresh: the front end refreshes the rate on a countdown so the number on screen stays current.

Vendor integrations

Eleven providers are lined up for direct integration: Pesa, Nala, Send, Taptap Send, Remitly, Wise, MonieWorld, LemFi, Sendwave, Grey and Access Bank. Each will be added as an adapter behind the same quote format, so the comparison logic and front end don't change as vendors are added.

Honest status: the market rate is live, but today's quotes are modelled estimates by transfer type (each quote is flagged isEstimate: true in the API), not each provider's own live price. The site says this on its Providers page.

What it shows

  • Designing a clean API contract that hides data-source differences.
  • Aggregation and ranking logic that turns raw rates into one clear answer.
  • Being transparent about data quality in a financial product.
